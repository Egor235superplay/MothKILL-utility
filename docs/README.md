# MothKILL

## Описание
Программа подключается к датчику УФ-излучения (основное) или к запаховому датчику (опционально)
и поражает/отпугивает насекомых (вроде пищевой или платяной моли и продуктов их жизнедеятельности).

## Установка
1) Клонируем репозиторий на свой ПК: git clone https://github.com/username/repository.git
2) Скачайте плагин "pest control" и "moth-detector", найти их можно в поиске в главном меню
3) После убедитесь, что плагины подключены и напишите команду в консоль "dstart"

## Использование
Подключите датчики и введите номер модели в нужное поле в приложении, дождитесь 
пока произойдет сопряжение. Далее настройте параметры в зависимости от уровня 
заражения и закройте все приложения, кроме ходового. Установите таймер, покиньте 
помещение на указанное время. 
Срок использования: 2 месяца.
